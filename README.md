# МАГНИТ РЦ — автоматизация Excel · версия 2.4

Адаптивный статический сайт для GitHub Pages. Excel обрабатывается **в браузере**, без отправки файлов на сервер. Создан на основе пользовательского образца `Отчет по Товарному запасу Ноябрь 2026 год(1).xls`.

## 1. Ежедневный товарный запас

В категории **«Товарный запас»** загрузите два `.xlsx` с **точными именами**:

1. `rep_turnover_saldo_for_logist_excel.xlsx` — сальдово-оборотная ведомость;
2. `rpt_levelservice_api.level_service_hd_gk_eday_hm.xlsx` — уровень сервиса.

Файлы проверяются по названию, расширению и обязательным заголовкам. «Дата операции» второго файла определяет дату товарного отчёта; допускается предыдущий день. Объединение производится по **коду товара**, операции суммируются по коду и дате.

При формировании Excel создаются:

- `ДД.ММ.ГГГГ` — ежедневная таблица с формулами;
- `НТЗ` — выбранный срез норм НК/КК, подставляемых формулами `VLOOKUP` по коду;
- `Архив НТЗ` — **полный** исторический архив из образца (расположенные рядом срезы; все записи);
- `код цветы` — отдельный список кодов цветов из образца;
- `Цветы` — товары, совпавшие с кодами цветов в текущих выгрузках; расчёт выполняется по форме листа «Цветы» образца;
- `УС` — агрегированные показатели уровня сервиса;
- `Контроль` — диагностические записи (в том числе товары без НК/КК).

**Оформление:** в Excel первая колонка «Код товара» залита голубым, заголовки показателей — синим, НК/КК и комментарии — зелёным, как в предоставленном скриншоте. НК/КК в итоговой таблице используют формулы ссылки на лист `НТЗ`, а не вручную переписанные числа.

### Нормативы и их архив

Обязательный первый шаг — импортировать исходный образец `.xls` или `.xlsx` через блок **«Нормативы НК / КК»**. Сайт считывает `НТЗ`, `Архив НТЗ` и `код цветы` и сохраняет данные **локально в браузере**.

Исходный образец содержит срезы:

- **НТЗ** за 24.10.2026 — 1 148 позиций;
- **Архив НТЗ** за 15.05.2026, 16.05.2026, 09.10.2026;
- **код цветы** — 1 904 строки кодов, из которых 1 878 уникальных.

Можно выбрать основной НТЗ либо конкретный архивный срез в выпадающем поле. При загрузке обновлённого образца ранее сохранённый основной срез автоматически переносится в архив, если дата нового основного среза изменилась; прежние срезы объединяются по дате. Интеграция истории не требует сервера.

**Без выдуманных нормативов.** Если для кода нет НК или КК в выбранном срезе, в ячейке появляется надпись `НЕТ В НТЗ` (красная заливка), а в лист `Контроль` записывается код и товар. Никакого автоматического проставления `0` или несанкционированного переноса норм другого периода нет. Прежде чем передавать отчёт в работу, необходимо проверить и устранить эти предупреждения.

### Формат отображения (версия 2.3)

- «УС отгрузки к заказу», «УС отгрузки к импорту» показываются как **проценты с двумя знаками**: `0,9094565` → `90,95%`, `1,3030303` → `130,30%`.
- Все числовые показатели в дневном отчёте, «Критике» и «Цветах» показываются **до двух знаков после запятой**: `1,3834893489` → `1,38`. Excel применяет числовой формат, а не округляет исходные значения и формулы.
- Когда рассчитанное отклонение от максимального НТЗ положительно или указано «Без расхода», столбцы «ТЗ/Заказ», «Целевой ТЗ Комментарии», «Максимальный ТЗ Комментарии» отмечаются красным, как на образце. Для «Нет в НТЗ» сохраняется отдельное предупреждение.
- В веб-предпросмотре действуют те же два формата; локаль `ru-RU` отображает запятую в дробной части.

### Расчёты

- УС к заказу = Отгрузка / Заказ;
- УС к импорту = Отгрузка / Импорт;
- ТЗ в днях = Конечное количество / Отгрузка;
- ТЗ / Заказ = Конечное количество / Заказ;
- Отклонения от НК и КК = Фактический ТЗ в днях минус выбранный норматив.

При нулевом знаменателе коэффициент равен 0; при нулевом заказе комментарий `Без расхода`.

## 2. Критика — исключительно сегодня / сегодня

Откройте отдельную категорию **«Критика»** и загрузите **ещё две отдельные** выгрузки `.xlsx` с теми же названиями, но данными для сегодняшнего дня. Сайт проверяет, что в «Уровне сервиса» есть операции **за текущую локальную дату браузера**. При отсутствии сегодняшней даты генерация блокируется. Дата исторического товарного отчёта при этом может быть вчерашней.

Критика формируется с 15 столбцами по форме исходного листа `Критика 10.11.2026`, без Vicherk; её можно скачать отдельно. Если критика за сегодня готова, она также добавляется отдельным листом в экспорт ежедневного товарного запаса. НК/КК и в критике берутся из выбранного НТЗ.

**Ограничение контроля даты:** сальдовая ведомость не имеет явного столбца даты, поэтому сайт не может доказать, что её выгрузили сегодня. Нужно самостоятельно проверить дату формирования этого файла. Сам критерий отбора позиций для критики пока **предварительный**: использует признаки «Овощи-фрукты» и коды образца; для полного совпадения с рабочей критикой потребуется показать правила отбора.

## 3. Возвраты ГТ

В разделе **«Возвраты ГТ»** можно открыть `.xls`/`.xlsx`, выполнить поиск по полям и скачать отфильтрованную выборку. Исходный файл не меняется.

## Размещение на GitHub Pages

1. Создайте репозиторий, например `magnit-rc-site`.
2. Загрузите в его корень `index.html`, `README.md` и каталог `assets` (каталог `tests` необязателен).
3. Перейдите в **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Откройте опубликованный сайт. При первом использовании импортируйте исходный ноябрьский `.xls`, затем ежедневно загружайте файлы из соответствующих категорий.

**Не добавляйте исходные Excel с коммерческими данными в GitHub!** Хранилище справочника `localStorage` используется только в данном браузере и не синхронизируется. Удаление данных браузера может очистить его — сохраните исходный `.xls` отдельно.

Для чтения новых Excel `.xlsx` используется локальный потоковый парсер `assets/xlsx-lite.js` (включён в архив). Два ежедневных `.xlsx` и сам экспорт **не зависят от CDN**. Архив НТЗ в формате `.xlsx` также читается локально. Старый двоичный `.xls` не является XLSX: для его открытия браузер попытается загрузить SheetJS по HTTPS. Если подключение заблокировано, откройте образец в Excel, сохраните как **`.xlsx`** и повторите импорт. Содержимое выбранных файлов не отправляется на сервер.

Для экспорта оформленного Excel используется **собственный локальный генератор XLSX**, расположенный в `assets/export.js`. При успешном формировании рядом с кнопкой появляется **резервная ссылка**: нажмите на неё, если браузер блокирует автоматическое скачивание. Ссылка остаётся доступной до формирования следующего отчёта или перезагрузки страницы.

## Известные моменты, требующие дальнейшего уточнения

- Отбор критических позиций и выборочная сверка итогов с ручным отчётом.
- При дублировании кода в сальдовой ведомости сейчас берётся последняя строка — требуется согласование.
- При нескольких РЦ агрегаты уровня сервиса пока суммируются без фильтра конкретного РЦ.
- У отдельных товаров из предоставленного примера нет норм ни в основном НТЗ, ни в архиве: значения не восстанавливаются искусственно.
- Исходные Excel обычно большие; браузеру потребуется оперативная память для чтения выгрузок, а полное визуальное воспроизведение всех скрытых объектов исторического `.xls` не заявляется.

## Версия 2.2 — Эталон кодов всех товарных позиций (21.11.2026)

В **`assets/etalon.js`** внедрён список из предоставленного файла **«Эталон.txt»**. В исходном файле 46 555 строк, из них **4 287 уникальных кодов** и 42 268 повторений. Повторные коды не создают повторные строки в отчёте. Исходный порядок первого появления каждого кода сохранён. Два нестандартных кода — `144428298` (9 цифр, строка 7003) и `80000129271000465885` (20 цифр, строка 39796) — **не исправляются автоматически**: они включены в Эталон и отмечены для контроля.

### Как пользоваться

1. В категории **«Товарный запас»** по умолчанию выбран режим **«Эталон — все товарные позиции»**.
2. Загрузите **две ежедневные таблицы с прежними точными именами**. Для норм НК и КК отдельно загрузите рабочий Excel со справочником **НТЗ**. НТЗ/Архив НТЗ по-прежнему хранятся локально в браузере.
3. Все **4 287 уникальных ТП** попадут в главный Excel-отчёт, даже если часть кодов отсутствует в сальдовой ведомости или уровне сервиса за выбранную дату. По коду подтягиваются найденные название, сальдо, операции и нормы. **Отсутствующие показатели остаются пустыми**. НК и КК без соответствия в НТЗ показывают «НЕТ В НТЗ»; отклонения при отсутствующих данных показывают «Нет данных».
4. В Excel появится **лист «Эталон ТП»**: по каждому коду отметки наличия в сальдо и УС за выбранную дату, НК/КК из НТЗ, контроль длины кода. Лист **«Контроль»** показывает не найденные ТП, недостающие нормативы и коды из исходных выгрузок, которых нет в Эталоне. Другие листы сохранены: **НТЗ, Архив НТЗ, код цветы, Цветы, УС**, при необходимости отдельно **Критика**.
5. Раздел **«Эталон ТП»** в левом меню показывает количество уникальных кодов, повторы, проверки длины и поиск. Можно загрузить обновлённый `.txt` и работать по нему в текущем браузере. Нажмите «Вернуть встроенный Эталон», чтобы отменить местное переопределение.

**Важное ограничение:** локальная загрузка нового Эталона не обновляет код GitHub Pages для других посетителей. Для глобального обновления нужно изменить `assets/etalon.js` и опубликовать обновлённый сайт. До обновления встроенный эталон остаётся прежним.

### Конфиденциальность

GitHub Pages и файлы его сайта **могут быть публично доступны**. Встроенные товарные коды находятся в `assets/etalon.js`, и посетитель сайта сможет их прочитать. Публикуйте этот вариант только если раскрытие списка товарных кодов допустимо. **Никакие ежедневные XLSX, НТЗ или архивы не включены в архив сайта.** Если номенклатура конфиденциальна, используйте локальное обновление списка вместо публикации встроенного перечня в открытом репозитории.

### Контроль работоспособности

Запуск автоматических проверок: `node tests/core.test.cjs`. Проверяются 4 287 уникальных кодов, отсутствие дубликатов в отчёте, строка без данных, внешний код, текстовое сохранение длинных кодов, Excel XML, формулы НК/КК, формат процентов и правила предыдущих версий.


## Версия 2.3 — исправление скачивания Excel (21.11.2026)

1. Если кнопка **«Скачать готовый отчёт Excel»** неактивна, под ней выводится причина. Для полного отчёта сначала нужны **обе ежедневные таблицы**, успешная обработка и **НТЗ**. НК/КК не подставляются без справочника.
2. В блоке формирования добавлена кнопка **«Проверить скачивание (тест Excel)»**. Она создаёт минимальный тестовый файл без исходных выгрузок — так можно проверить разрешение браузера на загрузку.
3. Готовый файл скачивается автоматически. Если загрузка не началась, нажмите появившуюся **резервную ссылку** под кнопками. Файл сохраняется с латинским именем `MAGNIT_TZ_ДД-ММ-ГГГГ.xlsx`; аналогично исправлена выгрузка «Критики» и возвратов ГТ.
4. Основные ежедневные `.xlsx` читаются **без интернета** локальным потоковым парсером. Проверено на исходных пользовательских файлах: **5 124** позиций в сальдо и **104 368** строк уровня сервиса; итоговая книга с **4 287** кодами Эталона создаётся, а ZIP-пакет Excel проходит проверку целостности и XML.
5. Для открытия **`index.html` двойным щелчком** браузер может блокировать `Web Worker`. Используйте размещённый сайт **GitHub Pages** или локальный HTTP-сервер (`python -m http.server 8000`).
6. После замены файлов сайта на GitHub нажмите **Ctrl+F5** на странице для обновления JavaScript. Загруженные Excel и справочник НТЗ в GitHub загружать не надо.

Проверка с использованием реального графического браузера в текущем окружении ограничена блокировкой доступа к HTTP/файловым URL браузерной средой; вместо неё выполнен интеграционный тест в JavaScript с реальными `.xlsx` и тест целостности сгенерированного файла.

## Версия 2.4 — исправлена выгрузка «Критики» (21.11.2026)

**Проблема:** раздел «Критика» использовал НТЗ, который можно было загрузить только в другом разделе; при отсутствии НТЗ, сегодняшней даты или подходящих ТП кнопка скачивания становилась неактивной без достаточно понятной инструкции.

**Исправления:**

1. В разделе «Критика» появился собственный загрузчик **«Загрузить НТЗ (.xls / .xlsx)»**. Он использует тот же справочник, что и «Товарный запас»: основной НТЗ, архив, коды цветов. Можно выбрать основной или архивный срез непосредственно в «Критике»; выбор синхронизируется с основным разделом.
2. Под кнопкой появляется точная причина блокировки: не загружены две отдельные таблицы, не проведена проверка, отсутствует **сегодняшняя** дата в уровне сервиса, не подключён НТЗ, выбранный режим не содержит ТП или отчёт устарел.
3. Добавлена независимая кнопка **«Проверить скачивание (тест Excel)»**. Она проверяет скачивание без исходных таблиц. Если обычное скачивание заблокировано браузером, доступна постоянная резервная ссылка в том же разделе.
4. Добавлен выбор **состава Критики**: «Овощи и фрукты (по признакам)» (предыдущий режим), «Эталон — все товарные позиции», «Все позиции из выгрузок» и «Только коды цветов». При нулевом отборе сайт предлагает выбрать другой режим.
5. Отдельный экспорт Критики теперь передаёт реальные `criticalSources` в лист сверки **«Эталон ТП»**. Нормативы НК/КК по-прежнему обязательны; «Критика» по-прежнему формируется строго на **текущий день по часам браузера**. Отчёт за вчера не будет молча обозначен сегодняшним.
6. Сохранены проценты и два знака после запятой, цветные колонки, предупреждения об отсутствующих нормативах, полная история НТЗ, справочник цветов и длинные товарные коды.

**Тесты:** `node tests/core.test.cjs`, `node tests/critical_download.test.cjs`. Тест критики проверяет чтение настоящих небольших XLSX через тот же модуль, дату «сегодня», блокировку иной даты, расчёт НК/КК, архив и структуру выгрузки. Дополнительно в Chromium офлайн проверены интерфейс, настоящий browser-download и fallback-ссылка на синтетических тестовых данных. Доступ к локальному HTTP-адресу в тестовой среде ограничен; поэтому прямой сценарий на размещённом GitHub Pages ещё нужно проверить после публикации.

**Как обновить:** замените в GitHub корневой `index.html` и содержимое `assets` из ZIP версии 2.4, затем откройте GitHub Pages с принудительным обновлением (`Ctrl+F5`). Не выгружайте реальные Excel в репозиторий. В «Критике» сначала загрузите две свежие выгрузки и НТЗ, нажмите «Проверить критику за сегодня», затем «Скачать критику Excel».
